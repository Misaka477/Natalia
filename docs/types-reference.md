## English

> This document is the companion to `docs/api-reference.md`: the API reference
> describes the protocol surface (routes, auth, events, failure kinds, the SDK
> method table), and this document gives the **complete field shapes** of every
> result type — nested objects are expanded into paths
> (`obj.field`, `arr[].field`, `?.field`), so no one has to open
> `@anthelia/contracts` source to know what a return value looks like.
>
> The tables under the "Machine-derived" heading below are generated from the
> source tables (`npm run docs:api-reference`) and are byte-identical with the
> Chinese edition; the drift guard
> (`packages/hosts/transport/test/api-reference.test.ts`) turns the gate red on any
> disagreement with the code.

## 1. How to use

1. Find a member's return type name in the SDK method table of the API
   reference (for example `RuntimeCheckpoint[]` or `CheckpointPreview`).
2. Find that type in the table below; nested objects are already expanded
   into path-bearing fields.
3. Notation: `?` = optional field; `arr[].field` = a field of each array
   element; `obj.field` = a field of a nested object; `?.field` = the child
   field exists only when its optional parent is present; unions are shown
   inline.

Example (`CheckpointPreview`): `changes[].kind` is the `kind` field of each
array element; `context.targetJournalOffset` is a field of the nested
`context` object.

## 2. Conventions

- The table covers every type reachable from the SDK's parameters and return
  types; after adding or renaming a type field, run
  `npm run docs:api-reference` to refresh it.
- Builtin generics (`Record<string, unknown>`, ...) and named type references
  are shown as-is; a named type's own fields are expanded on its own row.
- The event union family (`RuntimeEvent`/`RuntimeEventData`) is not repeated
  here — see the event dictionary in the API reference.
